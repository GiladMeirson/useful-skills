What's a skill, exactly?

A skill is a folder Claude Code reads before it works: one SKILL.md file describing when to use it and how, plus optional reference docs and helper scripts it opens only when needed. Drop the folder into .claude/skills/ inside a project — or into ~/.claude/skills/ to make it available in every project on your machine — and Claude picks it up automatically next session. No build step, no restart beyond starting a new session.

Install a skill

Every skill installs the same way — one line, no cloning the whole repo. It needs only npx, which already ships with Node, a Claude Code prerequisite.

npx degit GiladMeirson/useful-skills/skills/<skill-name> .claude/skills/<skill-name>

Swap <skill-name> for one of the five below — each skill card has this filled in with a copy button. Run it from your project's root. To install for every project instead of just this one, change the destination to ~/.claude/skills/<skill-name> (PowerShell: $HOME/.claude/skills/<skill-name>).

Prefer a guided picker? Clone the repo once and run ./install.sh (macOS/Linux/WSL/Git Bash) or ./install.ps1 (Windows PowerShell) with no arguments for an interactive menu — see the repo README.

#canvas-atelier

Canvas Atelier

Gallery-quality drawing & animation on HTML canvas — construction-based shapes, physically-based light and shadow, organic curves instead of geometric primitives, and animation-principle-driven motion.

  • draw / illustrate / render / animate on canvas
  • output should look "realistic" or "polished"
  • canvas games, generative art, particle effects
Key files
  • SKILL.md — the 8-stage workflow: composition → block-in → organic contour → light & shadow → texture → animation → performance → critique
  • references/composition.md — focal point, selective fidelity, depth, negative space
  • references/lighting-and-shading.md — core-shadow / cast-shadow / ambient-occlusion / rim-light model, with gradient code
  • references/organic-curves.md — turning primitives into natural, asymmetric contours
  • references/color-theory.md — shadow warmth relative to light temperature, saturation peak at the core-shadow transition
  • references/precision-and-form.md — perspective, value-before-color, lost-and-found edges
  • references/animation-principles.md — easing, squash & stretch, anticipation, arcs, follow-through
  • references/physics-motion.md — Verlet integration for cloth, hair, rope, flags
  • scripts/canvas-setup.js, easing.js, bezier-utils.js, noise.js, verlet.js — the helper code each stage calls
Example
Prompt

Draw a realistic red apple with a stem and a bit of shine, sitting on a wooden table, on an HTML canvas.

What Claude does

Sizes the canvas for the real display density first, blocks in the apple and table with low-opacity ovals to check proportions, replaces every curve with asymmetric beziers, picks one light source and shades with a graduated gradient (core shadow, cast shadow on the table, a thin rim light), adds a noise layer and a pinpoint specular highlight for the shine — then renders and checks the actual pixels against a critique checklist before calling it done.

Live, in this page

Same technique as the hero orb — core shadow, cast shadow, rim light, and a noise layer composited on an offscreen canvas so it respects the clip region, per the skill's own documented gotcha.

#physics-2d

2D Physics Engine

A small, tested rigid-body engine — gravity, collisions, bouncing, friction, stacking, joints, raycasting, and a deterministic fixed-timestep loop. For when motion must be simulated, not scripted.

  • objects fall, collide, bounce, pile up, swing
  • shot / thrown objects that respond to forces
  • rigid-body dynamics on a 2D (or 3D) canvas
Key files
  • SKILL.md — workflow: units → fixed-timestep loop → bodies from shapes → collisions & filtering → joints → raycasts → tuning
  • scripts/index.js — single entry point, imports all nine modules
  • scripts/world.js — the fixed-timestep loop, sleeping, anti-tunneling, filtering
  • scripts/body.js, shapes.js — RigidBody state, mass & moment of inertia, AABB
  • scripts/broadphase.js, collision.js — spatial-hash culling, SAT narrow phase, contact manifolds
  • scripts/solver.js — accumulated-impulse solver: restitution, Coulomb friction, split-impulse correction
  • scripts/constraints.js — distance / revolute / spring joints
  • scripts/raycast.js — hitscan, line-of-sight, picking, swept CCD
  • scripts/selftest.js — Node smoke tests (free-fall, stacking+sleep, friction, joints, filtering)
  • demo.html — a full interactive, tabbed demo of the engine
Example
Prompt

Crates fall from the top, land on a platform, and stack up — plus a cannon that can shoot a ball to knock them over.

What Claude does

Creates a World with gravity and a static platform body, spawns box RigidBodys with friction and restitution, drives everything through world.update(dt) on a fixed timestep with interpolated rendering, and wires the cannon's aim to world.raycast(...). The accumulated-impulse solver keeps the stack resting cleanly instead of jittering or gaining energy.

Live, in this page

A small flavor demo (gravity, wall bounce, circle–circle separation) — not the full engine. The real thing has a broad phase, sleeping, joints and raycasting; see demo.html in the repo.

#caveman

Caveman

Ultra-compressed replies — articles, filler, and hedging cut, all technical substance kept. The skill's own frontmatter claims a measured ~65% drop in output tokens. Supports lite / full / ultra, plus classical-Chinese (wenyan) variants.

  • "caveman mode" / "talk like caveman"
  • "less tokens" / "be brief"
  • typing /caveman
Key files
  • SKILL.md — the whole skill: rules, intensity levels, auto-clarity exceptions (security warnings, irreversible actions), and worked examples. No scripts or references — this one is pure response style.
Drops back to normal for security warnings, irreversible-action confirmations, and anywhere compression itself would create ambiguity — then resumes once that part is done.
Example — "Why does my React component re-render?"
full (default)

New object ref each render. Inline object prop = new ref = re-render. Wrap in useMemo.

ultra

Inline obj prop, new ref, re-render. useMemo.

lite

Your component re-renders because you create a new object reference each render. Wrap it in useMemo.

#matrix-agents-skill

Matrix Agents Skill

A meta-skill that turns coding sessions into new skills. Loaded every session, it silently tallies learning patterns — repeated fixes, regression chains, long exploration, architectural decisions — and at session end proposes turning the strongest one into a real, installable skill.

  • load in every session, any language or stack
  • triggers: /forge, /matrix, "forge", "matrix", פורג', מטריקס
  • proposes at most once per session, never mid-task
Key files
  • SKILL.md — the pattern table (11 signals across repetition, pain, exploration, decisions, environment), interview questions, and the routing-map format it writes to CLAUDE.md
Runtime files it manages inside a project, not shipped with the skill: .claude/skills/matrix-agents-skill/session-tally.md and declined.md. It also pairs well with the skill-creator skill, which it delegates the actual file-writing to when available.
Example — a real session's shape
Mid-session (one line, then keeps working)

🔨 Skill-worthy pattern detected (regression chain). I'll propose at session end — or type a trigger word now.

End of session

"Before we wrap up: I noticed fixing the sort broke pagination, then fixing pagination broke the filter. This suggests knowledge worth preserving as a skill so future sessions start with it. Want me to create one?"

#skill-report

Skill Report

A one-line transparency footer on every response, listing which skills, subagents, and web tools were actually used — computed from the transcript itself, not from asking Claude to recall what it did.

  • runs automatically, every turn
  • enforced by a Stop hook, not left to chance
  • typically installed per-project, not globally
Key files
  • SKILL.md — the footer format and why it needs a hook to be unconditional
  • scripts/report_hook.py — the Stop hook: reads the transcript, finds this turn's Skill / Agent / WebSearch / WebFetch calls, forces a continuation if the footer is missing
Example output
After a turn that used tools

Skill report: Skills: dataviz, skill-creator | Subagents: Explore | Web: WebSearch

After a plain-answer turn

Skill report: Skills: none | Subagents: none | Web: none

One extra step this skill needs: copying the folder isn't enough on its own — the Stop hook has to be registered in your project's .claude/settings.json too. If you don't already have a hooks block, add this (merge the Stop array in if you do):
{ "hooks": { "Stop": [ { "hooks": [ { "type": "command", "command": "python \"$CLAUDE_PROJECT_DIR/.claude/skills/skill-report/scripts/report_hook.py\"", "timeout": 15 } ] } ] } }
