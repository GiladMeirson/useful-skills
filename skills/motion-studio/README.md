# motion-studio

Motion-design videos made entirely in code — reels, explainers, launch films, animated logos, or your raw talking-head clip cut into a captioned reel — in **English or Hebrew (RTL)**. The agent writes the scenes in [Remotion](https://www.remotion.dev) (React), generates the voiceover, sound effects and music, mixes to platform loudness, and only hands the video over after automatic lint, layout and QA checks pass.

Free by default. ElevenLabs is a first-class option for voice, SFX and music when you want it.

```sh
# this project (Claude Code reads .claude/skills, Copilot reads it too)
npx degit GiladMeirson/useful-skills/skills/motion-studio .claude/skills/motion-studio

# every project on this machine

# or with the skills CLI (Claude Code, Codex, Cursor, Antigravity...)
npx skills add GiladMeirson/useful-skills --skill motion-studio
```

PowerShell: write `$HOME` instead of `~`. Or use the repo installer: `./install.sh motion-studio` / `.\install.ps1 motion-studio`.

For the Claude app (web/desktop): zip the `motion-studio` folder (the folder itself at the top of the zip) and upload it in your Skills settings. Note that claude.ai cloud sessions may block the free voice service and model downloads; the skill works best in Claude Code or a session linked to your own computer.

## Use it

Just ask. The skill triggers on video requests in English or Hebrew:

```text
Make a 20-second 9:16 reel in Hebrew about Dreamolizer, female voice.
Edit my raw clip public/footage/raw.mp4 into a reel: cut the silences, captions, punch zooms.
A 45-second 16:9 explainer of our dashboard, no voice, music and kinetic type only.
ריל של 20 שניות בעברית על האפליקציה שלי, קריינות ב-ElevenLabs ומוזיקה מ-ElevenLabs.
```

What happens, in order:

1. **Brief** — goal, audience, format, length, tone, language. Missing pieces get sensible defaults, stated out loud.
2. **Brand** — read from your site or repo (`brand.py`), or your saved personal style, or asked.
3. **Voice question** — no voice · free voice · offline voice · ElevenLabs · your own recording. It can play the same line in each voice so you choose by ear.
4. **Project** — `new_project.py` scaffolds a Remotion project with bundled fonts (Hebrew included) and a starter scene that already renders.
5. **Direction** — 2-3 different art directions as styleframes; you pick one.
6. **Script → score** — `roteiro.json` becomes voice (line by line, cached), a timeline and named cues. **Audio is the clock**: animation hooks to words, never to hand-typed frame numbers.
7. **Music & SFX** — synthesized in code, or generated by ElevenLabs. You hear the audio mix before any animation is rendered.
8. **Scenes** → **lint** → **dailies** (stills of every scene, measured for cut/overlapping/low-contrast text, assembled into a contact sheet the agent actually looks at) → **independent reviewer** → **render** → **QA gate** (codec, loudness -14 LUFS, flashes, frozen frames, reading speed).
9. **Delivery** — the MP4, the contact sheet, credits, and an honest list of what's still a warning or wasn't verified.

You approve the voice, the direction and the audio before the final render. Progress is logged in `PROGRESS.md`, so a new session continues where the last one stopped.

### Teach it your taste

After a render, say what you didn't like — "captions too small", "too many whooshes", "I love this font". Each reaction becomes a one-line rule in `~/.config/motion-studio/lessons.md`, which every project reads first. Your colors and fonts go to `~/.config/motion-studio/my-style.json`. Both live outside the skill folder, so reinstalling or updating never erases them.

## Voice, sound and music

| | Free (default) | ElevenLabs (optional) |
|---|---|---|
| Voice, Hebrew | edge-tts — `he-IL-HilaNeural`, `he-IL-AvriNeural` | `eleven_v4` (default), `eleven_v4_turbo`, `eleven_v3` |
| Voice, English | edge-tts — Andrew, Ava, Brian, Emma… · Kokoro offline | `eleven_multilingual_v2` (default) or `eleven_v4` |
| Word timings | real, per word | real, per character (fallback: pause-based / `align.py`) |
| SFX | `sfx.py` — whoosh, riser, impact, pop… synthesized | text prompt → `eleven_assets.py` |
| Music | `musicgen.py` — drums, bass, pads, sidechain, 5 moods, risers/impacts land on scene cuts | text prompt → `music_v2_5` |

`eleven_multilingual_v2` and `flash_v2_5` don't speak Hebrew; the scripts refuse them for Hebrew.

### ElevenLabs setup

1. Create a key at <https://elevenlabs.io/app/settings/api-keys> with Text to Speech, Voices (Read), Sound Effects, Music and User (Read).
2. Put it in **one** of:
   - the video folder's `.env` → `ELEVENLABS_API_KEY=...`
   - `~/.config/motion-studio/.env` (Windows: `%USERPROFILE%\.config\motion-studio\.env`) — shared by every project.
3. Check it without spending: `uv run <skill>/scripts/eleven.py check` (plan, credits left, voices).
4. Pick a voice: `uv run <skill>/scripts/eleven.py voices --lang he`.

Nothing is spent without your yes: `score.py --dry` and `eleven_assets.py --dry` print the characters/items and credits left first, and every generated line or prompt is cached so timing changes never re-spend. Never paste the key into chat.

In `roteiro.json`:

```json
"voice": {"provider": "elevenlabs", "lang": "he", "voice": "<voice_id>", "style": "[warmly]"},
"music": {"eleven": "warm minimal electronic, soft punchy drums, 110 bpm, no vocals"},
"scenes": [{"id": "hook", "say": [{"text": "חלמת משהו מוזר הלילה?"}],
            "cues": {"weird": "word:מוזר"},
            "sfx": [{"at": "weird", "eleven": "soft magical shimmer", "dur": 1.2, "gain_db": -18}]}]
```

A complete Hebrew script: [`examples/he-reel/roteiro.json`](examples/he-reel/roteiro.json).

## Hebrew

- Full RTL: `dir="rtl"` from the theme, words reveal right-to-left in sync with the voice, punctuation on the correct side, numbers and Latin words kept LTR.
- Bundled Hebrew fonts: Heebo, Rubik, Assistant, Frank Ruhl Libre, Secular One, Suez One (no network at render time).
- Pronunciation fixes with niqqud in `speak` or `lexicon.json` while the screen keeps the plain spelling.
- Hebrew transcription/alignment uses the [ivrit.ai](https://huggingface.co/ivrit-ai) Whisper fine-tune (GPU when available).
- Typography rules (no uppercase/negative tracking, sizes, reading speed ≤ 15 cps) in [`references/hebrew.md`](references/hebrew.md).

## Commands you'll see

```sh
python <skill>/scripts/doctor.py                                   # environment check
python <skill>/scripts/new_project.py videos/my-reel --lang he --format reels --voice edge
python <skill>/scripts/voice.py --lang he                          # the voice question
uv run <skill>/scripts/score.py --dry | --yes                      # voice + timeline + cues
uv run <skill>/scripts/musicgen.py --mood uplift --sec 20 --hits 3.2,7.7 -o public/audio/music.wav
uv run <skill>/scripts/eleven_assets.py --dry | --yes              # ElevenLabs SFX / music
uv run <skill>/scripts/mix.py public/timeline.json                 # ducking + loudness
python <skill>/scripts/lint.py
node <skill>/scripts/stills.cjs Showcase                           # dailies
node <skill>/scripts/render.cjs Showcase                           # final render
uv run <skill>/scripts/qa.py out/final.mp4 --profile reels         # gate
uv run <skill>/scripts/footage.py cut public/footage/raw.mp4       # raw clip -> jump cuts
```

The agent runs these itself; you rarely need to.

## Limits

- Remotion is free for individuals and companies up to 3 people; larger companies need a Remotion company license.
- The free edge voice uses Microsoft Edge's read-aloud service: fine for personal projects, no SLA, needs internet. Offline English falls back to Kokoro; there is no offline Hebrew voice.
- ElevenLabs output follows your plan's terms (free plan = personal use).
- Rendering is CPU-heavy: the 18-second 1080×1920 demo reel took under a minute on a 2-core cloud machine; a desktop PC is faster.
