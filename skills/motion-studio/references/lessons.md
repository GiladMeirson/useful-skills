# Lessons (user feedback rules)

Rules learned from the user's reactions to real renders. They override every default in this skill.
The live copy is `~/.config/motion-studio/lessons.md` (shared by every install and project; created from this file the first time a lesson is saved). Read it at the start of every project. Append new rules at the bottom, one line each, testable, with date and project:

`- [YYYY-MM-DD · project] rule — why (what the user saw)`

Keep it short: when two rules say the same thing, merge them. When a rule turned out wrong, delete it.
