# Motion Studio

Makes motion-design video in code, with audio and verification. The agent cannot see the video while it writes code, so the flow declares the direction before animating (`direction.json`), measures before rendering (`lint.py`), measures text in the frames (`layout.py`), measures whether the piece has its own direction or fell into the model's default look (`design.py`), goes through a reviewer that did not write the code, and only ships after a numeric gate (`qa.py`).

Paths are relative to this skill's folder (`<skill>`). Scripts with dependencies declare them inline (PEP 723): run with `uv run <skill>/scripts/x.py`. `voice.py` and `lint.py` use only the standard library. `stills.cjs` and `render.cjs` run with `node` from the project folder. **On Windows** call `python` instead of `python3`, and quote paths that contain spaces.

## Before anything: lessons and progress

- Read the user's lessons: `~/.config/motion-studio/lessons.md` (Windows: `%USERPROFILE%\.config\motion-studio\lessons.md`), falling back to `<skill>/references/lessons.md`. They are rules the user taught after watching earlier renders, shared by every project, and override the defaults in every other file.
- First time on a machine, or when a script fails for an environment reason: `python <skill>/scripts/doctor.py` and relay its fixes.
- If the project folder already has `PROGRESS.md`, read it and continue from the last open step instead of starting over. Update `PROGRESS.md` after every numbered step below (one line: step, status, files, open questions). A new session must be able to resume from it alone.

## Mandatory flow

1. **5-line brief**: goal, audience, format (16:9, 9:16, 1:1), length, tone and brand, **language (en / he)**. Missing format or length: assume 9:16 1080x1920, 30 fps, 20-30 s for social, 16:9 for explainers, and say what you assumed.
2. **Brand**: if there is a site, repo or product screenshot, run `uv run <skill>/scripts/brand.py` and use the `brand.json` it writes. If `~/.config/motion-studio/my-style.json` exists and no brand is given, use it as the brand (the user's personal style; `new_project.py` does this). No source at all: ask for colors and font; never invent a brand. Set `"lang": "he"` in `brand.json` for Hebrew. Details in `references/brand.md`.
3. **Voice question (always)**: run `python <skill>/scripts/voice.py --lang <en|he>` and ask the user the question it prints (no voice / free voice / offline voice / ElevenLabs / own recording). Offer `--audition "<first line>"` so they pick by ear. Don't choose for the user unless the request already answered it. Details in `references/narration.md`.
4. **Project**: `python <skill>/scripts/new_project.py <folder> --lang <en|he> --format <reels|youtube|square> --voice <edge|kokoro|elevenlabs|none>`. It copies the template, writes `brand.json` (lang, Hebrew font), a starter `roteiro.json`, an empty `direction.json`, `PROGRESS.md`, a minimal `src/scenes/Showcase.tsx` that already renders the narration word by word, keeps the worked example in `reference/Showcase.example.tsx`, and runs `npm install`. Then copy the brand's `brand.json` into `public/` if step 2 made one. Map in `references/template.md`. Fonts are bundled (`src/fonts.ts`), no network needed at render time. Hebrew script to start from: `<skill>/examples/he-reel/roteiro.json`.
5. **Direction (before any scene)**: read `references/design.md`, `references/direction.md` and `references/doctrine.md`; for Hebrew also `references/hebrew.md`. With a user reference video, run `reference.py analyze` first and follow `references/reference.md`. Build 2-3 genuinely different directions, one styleframe each, join them with `contact_sheet.py --images` and show the user to choose. Save the choice in `direction.json` (concept, visual law, motif, and per scene: layout, entrance, hero). If the user explicitly delegated the choice, choose, write `"approved_by": "agent"` and say so at delivery.
6. **Script and score**: write `roteiro.json` (scenes, lines, named marks, SFX; set `voice.lang`). `uv run <skill>/scripts/score.py --dry` reports how many paid characters would be spent (0 for edge/kokoro) and, for ElevenLabs, the model and the credits left; say both and wait for a yes before `--yes`. ElevenLabs Hebrew needs `eleven_v4` (default for `lang: he`), `eleven_v4_turbo` or `eleven_v3`; `eleven_multilingual_v2`/`flash_v2_5` don't speak Hebrew and score.py refuses them. The script generates the voice line by line, the score (`public/timeline.json`) and the marks (`public/cues.json`). **Audio is the clock**: visuals follow it. No scene stores a hand-written frame number. Format in `references/score.md`.
7. **Music and SFX**: default is `musicgen.py` — a full bed synthesized in code (drums, bass, pads, plucks, sidechain, reverb; moods calm/uplift/corporate/tense/hype) with `--hits` = the scene-cut seconds from `public/timeline.json` so risers and impacts land on the cuts. For a real track: `music.py` (Incompetech CC-BY, then Openverse). `beats.py` when cutting on the beat. SFX are synthesized in code by `sfx.py` (whoosh, swoosh, riser, impact, click, pop, tick, shimmer) — no samples, no license. **ElevenLabs** (when the user chose it or asks for it): an SFX event `{"at": "cue", "eleven": "<prompt>", "dur": 1.2}` or a music bed `"music": {"eleven": "<prompt>"}` in `roteiro.json`; after `score.py` run `uv run <skill>/scripts/eleven_assets.py --dry`, tell the user the list and credits left, then `--yes`. Each prompt is generated once and cached. Every downloaded or generated file goes into `credits.json`. Details in `references/audio.md`.
   **Audio approval (with voice)**: run `mix.py` and give the user `public/audio/mix.wav` to listen to before animating. A request that only changes the voice redoes `score.py` and `mix.py` and goes back to the user, without render and without contact sheet.
8. **Scenes**: `<Scene id>` and `useScene(id).at('mark')` give timing; `theme.ts` gives color, font, `DIR`/`IS_RTL`; `useFormat()` gives scale and safe area. Look for a ready block in `references/blocks.md` first; only then compose from primitives. Read only the reference for the technique you'll use (router below).
9. **Lint (before every render)**: `python <skill>/scripts/lint.py` in the project folder. Fix every FAIL; weigh every WARN.
10. **Dailies**: `node <skill>/scripts/stills.cjs <Composition>` renders start, middle and end of each scene in one process and measures the text of each frame. `uv run <skill>/scripts/layout.py out/stills --timeline public/timeline.json` fails cut, overlapping, tiny, low-contrast or out-of-safe-area text. `uv run <skill>/scripts/design.py out/stills --timeline public/timeline.json` counts the model-default signals: with the verdict "model default", go back to direction before polishing. `contact_sheet.py --stills out/stills` builds the sheet. LOOK at the image, review with the checklist in `references/qa.md`, fix and repeat until there's no FIX. Never call `remotion still` in a loop.
11. **Independent reviewer**: give the contact sheet and the brief to a clean-context subagent with the text of `references/critic.md`. Whoever wrote the scene doesn't approve it. Without a subagent, say at delivery there was no independent review.
12. **Mix, render, deliver, gate**:
    ```bash
    uv run <skill>/scripts/mix.py public/timeline.json
    python <skill>/scripts/gl.py Showcase                      # once per project: measures the graphics backend
    node <skill>/scripts/render.cjs Showcase                   # or --formats reels,square,youtube
    uv run <skill>/scripts/deliver.py out/render.mp4 -o out/final.mp4
    uv run <skill>/scripts/qa.py out/final.mp4 --profile reels --timeline public/timeline.json --stills out/stills
    uv run <skill>/scripts/contact_sheet.py out/final.mp4 --timeline public/timeline.json -o out/sheet.png
    ```
    Fix after render: `render.cjs Showcase --scene <id>` redoes only that scene and re-assembles the master. Full renders have a budget (`budget.full_renders`, default 4). Only deliver with `qa.py` without FAIL.
13. **Honest delivery**: the MP4, the contact sheet, credits text and a list of what stayed WARN, who approved the direction, every resource that fell back (voice, music, format, simplified scene) and what was not verified.
14. **Learn**: when the user reacts to a render ("the captions are too small", "too many whooshes", "I like this font"), turn each reaction into one short, testable rule (with the date and the project) and append it to `~/.config/motion-studio/lessons.md` — create the folder, and seed the file from `<skill>/references/lessons.md`, the first time — so every project and every install shares it. Never write lessons inside the skill folder: reinstalling the skill would erase them. Style preferences (colors, fonts, pacing) go into `~/.config/motion-studio/my-style.json` (a `brand.json`). Tell the user in one line what you saved.

## Non-negotiable rules

- All visual state derives from `useCurrentFrame()`. Forbidden: CSS transitions/animations, `animate-*` classes, `setTimeout`, `Date.now()`, `Math.random()` (use `random(seed)`), React Three Fiber's `useFrame()`. Otherwise the render flickers or diverges from the preview. `lint.py` fails it.
- Curves and springs only from the tokens in `src/lib/motion.ts`: entrance `enter` or `sharp`, exit `exit`, position/shape change `move`, zoom-out and reveal `settle`, scene hero `easeX.emphasized`, `linear` only for continuous rotation and loops. Never `bounce` or `elastic`. One overshoot only (`easeX.overshoot` or `springs.snappy`), only on the element in focus. `interpolate()` without `easing` is linear: use `tween()` or `keys()`.
- Time comes from the score, color from the theme. Scenes don't write frames or loose hex: `useScene(id).at('mark')` and `C.*`.
- Each scene has its own layout, entrance and hero, declared in `direction.json`. Neighboring scenes don't repeat the layout+entrance pair. One visual motif runs through the piece; it doesn't become the same card in every scene.
- Real images only from licensed stock (`stock.py`) or the user's. No recognizable faces, brands or recent third-party works in commercial pieces.
- From a reference, reproduce structure, rhythm and technique. Never its frames, assets, logo, text, music or voice.
- One primary action at a time; secondaries up to 30% of its amplitude and ambient up to 5%. Total stagger up to 500 ms. Exit lasts ~75% of the entrance. First animation starts 0.1-0.3 s after the cut. After every arrival, hold 0.4-0.8 s; pause 0.3-0.75 s before the climax.
- Text stays on screen at least 1.5 s + 0.3 s per word, at most 17 characters per second (Hebrew: 15). Max 2 lines of 32-42 characters.
- Hook in the first 3 seconds: the first frame already shows something legible and the first spoken line states the payoff.
- Safe area: action inside 90% of the frame, text inside 80%. In 9:16 (1080x1920) text between y 360 and 1420. Type 28 px or more on the 1080 short side. Decorative text that bleeds off the frame on purpose gets `data-decor`.
- Motion blur only on 1-3 fast beats per video, never on text that must be read.
- Nothing that looks AI-generated: no full-screen purple gradient, no fade-in on everything, no generic glow, no emoji, not everything centered. One accent color, WCAG AA contrast.
- No invented number, logo or fact on screen. User data or sourced.
- Music only with license `cc0`, `pdm` or `by` (or generated). Never `nd`, `sa`, `nc`, sampling+ or unknown.
- API keys never go in chat, commands, logs or versioned files. The user writes them into the project's `.env` or once into `~/.config/motion-studio/.env`. Never spend ElevenLabs credits without a yes on the `--dry` numbers.
- Hebrew: `dir="rtl"` on every text container (theme gives `DIR`), never uppercase or negative tracking on Hebrew, Hebrew-capable font only, numbers and Latin words stay LTR inside RTL lines. See `references/hebrew.md`.

## Voice and audio commands

```bash
python <skill>/scripts/voice.py --lang he                          # the voice question
uv run <skill>/scripts/voice.py --lang he --audition "שורה ראשונה." -o out/voices   # same line in each free voice
uv run <skill>/scripts/score.py --dry                               # what would be generated + paid chars
uv run <skill>/scripts/score.py --yes                               # voice per line + score + marks
uv run <skill>/scripts/tts.py script.txt -o public/audio/narration --lang he         # one-off narration
uv run <skill>/scripts/align.py public/audio/narration.wav script.txt --lang he     # word timings for any WAV (Hebrew: ivrit-ai Whisper)
uv run <skill>/scripts/align.py footage.mp4 --transcribe -o public/audio/speech --lang he   # speech of footage, no script
uv run <skill>/scripts/tts.py --normalize-only "It costs \$49.90 at 2:30pm" --lang en      # check pronunciation
uv run <skill>/scripts/music.py incompetech --feel calm --bpm 70-110 --min-sec 60 -o public/audio/music.mp3
uv run <skill>/scripts/musicgen.py --mood uplift --sec 20 --key D --hits 3.2,7.7,12.8 -o public/audio/music.wav   # offline, synced to cuts
uv run <skill>/scripts/beats.py public/audio/music.mp3 --fps 30
uv run <skill>/scripts/sfx.py --all public/audio/sfx
uv run <skill>/scripts/footage.py cut public/footage/raw.mp4 -o public/footage/edl.json        # raw clip -> jump cuts
uv run <skill>/scripts/eleven.py check                               # ElevenLabs key, plan, credits left
uv run <skill>/scripts/eleven.py voices --lang he                    # account + library voices for Hebrew
uv run <skill>/scripts/eleven_assets.py --dry                        # ElevenLabs SFX/music the score asks for (then --yes)
python <skill>/scripts/doctor.py                                     # environment check
python <skill>/scripts/new_project.py videos/my-reel --lang he        # new project
```

## When to stop and ask

- The voice question in step 3 and the direction choice in step 5.
- Logo, brand, number or testimonial the user didn't provide.
- Before spending on a paid API (ElevenLabs voice, SFX, music): say the `score.py --dry` / `eleven_assets.py --dry` numbers and wait for a yes.
- Music with a license other than cc0, pdm or by.
- Full-render budget exceeded: say what's left to check and why stills aren't enough.
