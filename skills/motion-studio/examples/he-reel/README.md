# Hebrew reel example (roteiro.json)

A complete Hebrew script for a 9:16 reel, to copy and adapt. Shows:
- free Hebrew voice (edge, Hila) as the default, with ElevenLabs v4 and Avri as drop-in alternatives (`_voice_alternatives`);
- `speak` with niqqud teaching the pronunciation of a brand name while the screen shows the plain spelling;
- an ElevenLabs SFX on a cue (`"eleven": "..."`, generated by eleven_assets.py) next to procedural ones (`"type"`);
- an ElevenLabs music bed alternative (`_music_alternative_elevenlabs`: rename it to `music` to use it).
Keys starting with `_` are ignored by score.py.
